How a turn runs

Every tool call the model makes passes two local hooks before it executes. There is no sandbox underneath: these hooks are the only isolation layer in front of the trusted projects, which is why the repo treats them as untouchable without a matching smoke test.

Models, credentials and billing

No config file holds a raw key. Metered providers resolve their key from the macOS Keychain at call time; Codex runs on an OAuth subscription; Ollama is local and free.

Context and cost controls

Native compaction

  • reserveTokens 16,384 · keepRecentTokens 20,000
  • showCacheMissNotices on
  • Retry: 3 attempts, 2 s base delay; provider retries 0, max delay 60 s

pi-condense (contextPrune)

  • Prunes on agent message, batched per turn, min 1,000 chars
  • Chain compression over a rolling window of 3; error purging after 2 turns
  • Dedup by content hash; spill to disk above 64 KB
  • Never prunes .env*, auth.json, .ssh, .gnupg, node_modules, .git

Prompt caching

  • LLMHub Claude models need cacheControlFormat: "anthropic", or every token bills at full price
  • cache-warm prevents cold-cache misses after idle gaps
  • Root cause and numbers: prompt-cache-analysis.md

Visibility

  • /session-stats: current session, including advisor and architect calls
  • scripts/session-usage-report.py: all sessions, flags zero-cache-read sessions. Counts main-model turns only (see Actions)
  • statusline-pi shows live cost

Web search

Everyday lookups go through a cheap, sequential route with a local metasearch engine first. The multi-provider fan-out is reserved for decisions that matter and runs only through the /high-stakes-web-research template.

Maintenance and change rules

Scripts

  • smoke-test-extensions.sh: load with and without tools; permission-gate blocks a dangerous and a credential command and allows a benign one; protected-paths blocks .env via tool and via bash redirection, allows read-only mentions; git-checkpoint behaves in git and non-git dirs; architect loads (A1), disables cleanly (A2) and refuses past its cap (A3). 13 checks. Default model sonnet-5, overridable with --model.
  • session-usage-report.py: cost and cache report across all sessions and archives.
  • archive-old-sessions.sh: archives sessions older than 90 days; --dry-run first.

Rules from AGENTS.md

  • Validate the three JSON configs after every edit; a syntax error breaks every pi session on the machine.
  • Any guardrail change ships with a new smoke-test case.
  • Diff the public surface (commands, tools, widgets, settings keys); update README and the decision log.
  • Take a timestamped .bak before scripted edits to live config.
  • Never commit a raw key; grep apiKey must show only Keychain references.
  • Never reintroduce @mariozechner/* imports or the non-existent session_switch/session_fork events.

Actions that prevent the known problems

Ordered by what they protect. The first three are small code changes; hand them to the local agent together.

P1
Tool allowlists are overridden. architect.ts re-adds itself to the active tools in refresh(), which runs on session start, every before_agent_start and every call. advisor-pi does the same on session start. A run started with --tools read,grep or --no-tools (smoke tests, a future child process) still gets both tools. Prevent: only remove the tool in refresh() when disabled; add it back only in /architect enable. Verify with pi -p --tools read "list your tools". Report the advisor-pi behaviour upstream.
P1
The smoke gate spends real model calls. A3 makes three gpt-5.6-terra calls at high thinking to reach the cap, on every run of a gate meant to run after any extension edit. Prevent: read an env override such as PI_ARCHITECT_MAX_USES at load; A3 sets it to 0 and expects a refusal on the first call, with no model call.
P2
All-sessions spend is undercounted. session-usage-report.py reads assistant messages only. Prevent: apply the same rules as session-stats.ts: toolResult usage, details.advisor/architect.usage, compaction and branch-summary entries.
P2
LLMHub cache fix unverified. Config is right, but no live cache read has been seen since the €275 incident. Prevent: one short two-turn session on llmhub/claude-sonnet-4.6 after the budget resets, then check cacheRead > 0 in /session-stats.
P2
Flaky gate. Model-dependent checks can fail for reasons unrelated to the change. Prevent: on a red run, re-run once; if it passes, log it as a flake with the case name. Two flakes on the same case means rewording that prompt.
P2
No sandbox. Guardrails are regex and substring checks; pi-web-access fetches any URL. Prevent: keep trusted projects free of untrusted input, or run such work in a container per pi's containerization guide.
P3
Cap behaviour untested in a real session. The logged B5 checked /session-stats, not the cap. A3 covers the refusal, but not that main says so and carries on. Run once interactively.
P3
Fresh-context review of the finished diff. Try earendil-works/pi-review for two weeks; keep it only if it finds something the in-session review missed.
P3
Small things. /architect thinking rejects max, which pi supports; lastChangelogVersion still reads 0.85.1; claude-opus-4.6 on LLMHub unconfirmed.
