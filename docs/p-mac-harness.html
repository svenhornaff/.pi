How a turn runs

Every tool call the model makes passes two local hooks before it executes. There is no sandbox underneath: these hooks are the only isolation layer in front of the trusted projects, which is why the repo treats them as untouchable without a matching smoke test.

Models, credentials and billing

No config file holds a raw key. Metered providers resolve their key from the macOS Keychain at call time; Codex runs on an OAuth subscription; Ollama is local and free.

Context and cost controls

Native compaction

  • reserveTokens 16,384 · keepRecentTokens 20,000
  • showCacheMissNotices on
  • Retry: 3 attempts, 2 s base delay; provider retries 0, max delay 60 s

pi-condense (contextPrune)

  • Prunes on agent message, batched per turn, min 1,000 chars
  • Chain compression over a rolling window of 3; error purging after 2 turns
  • Dedup by content hash; spill to disk above 64 KB
  • Never prunes .env*, auth.json, .ssh, .gnupg, node_modules, .git

Prompt caching

  • LLMHub Claude models need cacheControlFormat: "anthropic", or every token bills at full price
  • cache-warm prevents cold-cache misses after idle gaps
  • Root cause and numbers: prompt-cache-analysis.md

Visibility

  • /session-stats: current session
  • scripts/session-usage-report.py: all sessions, flags zero-cache-read sessions
  • statusline-pi shows live cost

Web search

Everyday lookups go through a cheap, sequential route with a local metasearch engine first. The multi-provider fan-out is reserved for decisions that matter and runs only through the /high-stakes-web-research template.

Maintenance and change rules

Scripts

  • smoke-test-extensions.sh: load with and without tools; permission-gate blocks a dangerous and a credential command and allows a benign one; protected-paths blocks .env via tool and via bash redirection, allows read-only mentions; git-checkpoint behaves in git and non-git dirs. Default model sonnet-5, overridable with --model.
  • session-usage-report.py: cost and cache report across all sessions and archives.
  • archive-old-sessions.sh: archives sessions older than 90 days; --dry-run first.

Rules from AGENTS.md

  • Validate the three JSON configs after every edit; a syntax error breaks every pi session on the machine.
  • Any guardrail change ships with a new smoke-test case.
  • Diff the public surface (commands, tools, widgets, settings keys); update README and the decision log.
  • Take a timestamped .bak before scripted edits to live config.
  • Never commit a raw key; grep apiKey must show only Keychain references.
  • Never reintroduce @mariozechner/* imports or the non-existent session_switch/session_fork events.
