## Task text (pasted verbatim into every run)

I'm about to add support for a new `step` parameter on `IntRange`/`FloatRange`
that restricts accepted values to a fixed step from `min` (e.g. `min=0,
step=5` only accepts 0, 5, 10, ...). Before I write any code: walk me through
exactly how a value typed on the command line becomes a call into a
`ParamType`'s `convert()` for an `Option` using `IntRange` — which
file(s)/class(es)/method(s) are involved end-to-end, in call order. Also tell
me exactly where the existing range-violation error message is built and
where `IntRange` and `FloatRange` share code today, since that's where a
`step` check would need to be added once. Give exact `file:line` references
for every claim.
